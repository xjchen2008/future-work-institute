# Agent Employee Training Kit

This kit is part of the Future Work Institute Agent Employee Training Pilot.

## Included files
- `role-definition.md`
- `workflow-harness.md`
- `policy-boundaries.md`
- `weekly-review.md`

## How to use this kit
1. Define the agent's job clearly in `role-definition.md`
2. Turn one recurring workflow into a training harness in `workflow-harness.md`
3. Write approval/refusal/safety rules in `policy-boundaries.md`
4. Run a weekly review and document drift/improvements in `weekly-review.md`

## Goal
The goal is to turn an OpenClaw agent into a clearer, safer, more reliable employee for one real workflow.
