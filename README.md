# Future Work Institute

Static website concept for Future Work Institute.

## Purpose

A landing page for the idea of a school / proving ground / career center for AI operators.

## Files

- `index.html` — first website draft
- `DEPLOYMENT.md` — notes for moving this into the existing Cloudflare/static site flow

## Recommended deployment approach

Do **not** overwrite the current RFIC portfolio site.
Instead, publish this as:
- a separate repo/site, or
- a subdirectory/subdomain in the current Cloudflare flow

Recommended options:
1. `futureworkinstitute.com` or similar custom domain
2. subdomain like `fwi.xjchen2008.workers.dev`
3. subpath on an existing static site if you want a quick prototype
